# Catatan Minggu 01: Paradigma Pemrograman dan Setup

## 1. Yang Saya Kerjakan

Saya membuat tiga program sapaan menggunakan paradigma prosedural, OOP, dan fungsional. Saya juga mengisi data nama dan NIM pada file `mahasiswa.properties`. Setelah itu, saya menjalankan pengujian Minggu 1 hingga berhasil.

## 2. Keputusan Desain

Saya menggunakan kalimat sapaan yang sama pada ketiga program, yaitu menampilkan nama dan NIM mahasiswa. Tujuannya agar perbedaan ketiga paradigma lebih mudah dipahami dan dibandingkan.

## 3. Kendala

Saya mengalami kendala ketika menjalankan script pengujian karena PowerShell memblokir eksekusi script. Saya mengatasinya dengan menjalankan script menggunakan `ExecutionPolicy Bypass`. Setelah itu, pengujian berhasil tanpa kegagalan dan error.

## 4. Penggunaan AI

- **Alat yang dipakai:** ChatGPT.
- **Bagian yang dibantu AI:** Saya menggunakan ChatGPT untuk membantu memahami kode Java, perbedaan paradigma pemrograman, dan cara memperbaiki kendala yang muncul saat mengerjakan tugas.
- **Prompt utama:** Saya meminta penjelasan mengenai kode Java, fungsi dari setiap bagian program, serta bantuan memahami cara menjalankan pengujian proyek.
- **Yang saya ubah atau tolak dari saran AI, dan alasannya:** Saya menyesuaikan kode dan langkah pengerjaan dengan struktur proyek serta instruksi tugas dari dosen. Saya juga memeriksa kembali kode yang digunakan agar sesuai dengan kebutuhan program dan hasil yang diharapkan.
- **Satu hal yang saya pahami lebih baik sekarang:** Saya lebih memahami bahwa paradigma prosedural berfokus pada fungsi atau langkah-langkah untuk menyelesaikan tugas, paradigma OOP mengorganisasi program menggunakan class dan objek, sedangkan paradigma fungsional memanfaatkan fungsi sebagai bagian utama pengolahan program. Saya juga mulai memahami penggunaan fungsi statis, atribut `private`, konstruktor, dan lambda dalam Java.
